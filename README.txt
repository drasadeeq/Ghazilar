غازىلار ساقلىق مەركىزى — GitHub غا يوللاش

1) بۇ ZIP نى ئېچىڭ (ئاۋال ئېچىپ، ئىچىدىكى ھۆججەتلەرنى يوللاڭ).
2) GitHub رېپوزىتورىيەسىدە: Add file > Upload files.
3) ئىچىدىكى ھەممە ھۆججەتنى (index.html، firebase-messaging-sw.js، manifest.json، icon-192.png، icon-512.png، assetlinks.json، netlify.toml) يوللاڭ، كونىلىرىنى ئالماشتۇرۇڭ.
4) .github/workflows/build.yml نى مۇشۇ يول بىلەن قۇرۇڭ (Add file > Create new file، نامىغا .github/workflows/build.yml دەپ يېزىپ، ئىچىدىكى كودنى چاپلاڭ).
5) Commit changes. Actions > Build APK تاماملانغاندا Artifacts > ghazilar-apk نى چۈشۈرۈڭ.
6) كونا ئەپ ئۈستىگە ئورنىتىڭ (ئىمزا ئوخشاش بولسا يېڭىلىنىدۇ).
